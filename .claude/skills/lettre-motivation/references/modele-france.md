# Modèle français — structure détaillée

Même base que le modèle suisse (voir [modele-suisse.md](modele-suisse.md)), avec les ajustements ci-dessous. Voir [differences.md](differences.md) pour le tableau comparatif complet.

## Ce qui change par rapport au modèle suisse

1. **Pas de mention des pièces jointes.** Supprimer complètement la ligne "En pièces jointes : ..." sous la signature — ce n'est pas un usage français standard, et l'ajouter sonnerait déplacé.
2. **Formule de politesse finale plus développée.** Le sobre "mes meilleures salutations" suisse peut être remplacé par une formule plus étoffée si le ton du poste s'y prête, par exemple :

   ```
   Dans l'attente d'un retour favorable de votre part, je vous prie d'agréer,
   Madame, Monsieur, l'expression de mes salutations distinguées.
   ```

   Ou, plus sobre et cohérent avec le style habituel de Killian (voir [exemples.md](exemples.md)) :

   ```
   Je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations
   distinguées.
   ```

   Les deux sont acceptables ; préférer la version sobre par défaut sauf si l'utilisateur demande plus de formalisme (grand groupe, administration).
3. **Plus de liberté sur la structure.** Le triptyque Vous-Moi-Nous reste un bon fil conducteur mais n'a pas besoin d'être aussi rigide que côté suisse — on peut fusionner ou réordonner les paragraphes si ça sert mieux le propos.
4. **Format d'envoi.** PDF courant, mais en France beaucoup d'entreprises tech ne demandent plus de lettre formelle : un message d'accompagnement dans l'e-mail ou sur la plateforme de recrutement peut suffire. Si l'utilisateur indique que c'est le cas, proposer une version plus courte et moins formelle (message, pas lettre en bloc) plutôt que de forcer le format complet.
5. **Ton.** Peut rester un peu plus formel/littéraire que le modèle suisse selon le secteur (grand groupe, administration) — sinon rester dans le registre factuel et concret habituel.

## Ce qui reste identique au modèle suisse

- En-tête candidat, bloc entreprise, lieu et date, objet, formule d'appel (jamais "Bonjour"), structure en trois parties, signature.
- Une page maximum, paragraphes courts, exemples concrets valorisés.
